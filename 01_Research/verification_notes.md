# Verification Notes

## Framework verification

The assessment is based on **NIST AI RMF 1.0 (NIST AI 100-1)**. NIST describes the Core as four functions — Govern, Map, Measure, and Manage — with Govern operating as a cross-cutting function.

## Use-case verification

The organization, governance committee, internal policies, incidents, and operating data in this project are fictional constructs created for portfolio purposes.

## Risk-rating verification

The final report deliberately uses qualitative **Low / Medium / High / Severe** judgments rather than pretending that the exercise has statistically derived risk probabilities.

## Regulatory verification boundary

The final report contains a September 2026 snapshot of RBI and DPDP context. Because regulatory status can change, those statements must be rechecked before being used for a real compliance decision.

## Editing principle

No unsupported claim about Northstar's real-world operations, incident history, vendor relationship, or compliance posture should be inferred from this project.
